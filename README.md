# 📚 StudyLens AI

**StudyLens AI** is an AI-powered mobile study assistant built with **Flutter** and **Google Gemini** to make studying faster, simpler, and more interactive.

Instead of manually going through long study material, students can provide their content and let AI transform it into useful learning resources.

## ✨ Features

* 📝 **AI Summary** — Generates concise summaries from study material.
* 💡 **Key Concepts** — Extracts the most important concepts to focus on.
* 🧠 **Simple Explanation** — Explains difficult topics in easy, student-friendly language.
* ❓ **AI-Generated Quizzes** — Creates multiple-choice questions based on the provided material.
* 📊 **Quiz Results** — Shows the student's performance and correct answers.
* 📖 **Study-Friendly UI** — Clean, modern, and student-focused interface.
* ⚡ **Loading & Error Handling** — Provides feedback during AI processing and handles API/network errors gracefully.

## 🛠️ Tech Stack

* **Flutter & Dart** — Mobile application development
* **Google Gemini API** — AI-powered study material generation
* **HTTP** — API communication
* **flutter_dotenv** — Environment configuration
* **Material Design** — UI components and theming

## 🔄 How It Works

```text
Study Material
      ↓
Flutter Application
      ↓
Google Gemini AI
      ↓
Structured Study Content
      ↓
Summary + Key Concepts
      ↓
Simple Explanation + Quiz
      ↓
Interactive Quiz & Results
```

## 🎯 Project Goal

The goal of StudyLens AI is to provide students with a simple tool that can turn their existing study material into personalized learning resources, helping them understand important concepts and test their knowledge more effectively.

## 🚀 Project Status

StudyLens AI is an actively developed Flutter project. The current version focuses on AI-powered study material generation, structured learning content, and interactive quizzes.
